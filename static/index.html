SignVerify

전자서명과 해시를 활용한 문서 위변조 검증 서비스

키 쌍 생성 및 공개키 등록

RSA 2048비트 키 쌍을 브라우저에서 만듭니다. 서버에는 공개키만 보내고, 개인키는 비밀번호로 암호화된 파일로 내 PC에만 저장됩니다.

문서 서명

문서의 SHA-256 해시를 브라우저에서 계산하고, 개인키로 RSA-PSS 서명합니다.

문서 검증

서버가 업로드된 문서의 해시를 다시 계산하고, 작성자의 공개키로 서명을 검증합니다.
